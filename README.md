# Aşk Kutusu

Create a modern, highly interactive, and responsive web application in Turkish built with React, Tailwind CSS, Lucide icons, and Framer Motion animations to celebrate the 15th-month anniversary of Derya and Javanshir. The theme must be warm, romantic, stress-relieving, and tailored for a long-distance relationship using pastel pink, deep rose, and soft white tones.

Include the following detailed features and structure:

1. Personalized Header & Hero Section:

   - Display a main banner: "15. Ayımız Kutlu Olsun, Derya & Javanshir! ❤️"

   - Include a live countdown clock widget titled "Kavuşmamıza Kalan Süre" showing days, hours, minutes, and seconds until the next reunion.

   - Include an interactive "Seni Çok Özledim" button that generates floating heart particle effects across the screen when clicked.

2. Mini-Games & Secret Code Unlock System:

   - Mini-Game 1: "Hafıza Kartları" (Memory Match Game with romantic icons/card flips).

   - Mini-Game 2: "Aşk Balonları" (Pop floating heart balloons before they float away to reach a target score).

   - Reward Mechanism: Upon winning or completing each game, display a victory popup revealing a "Gizli İpucu / Şifre" (e.g., a special date format like '15.05.2025' or a specific romantic keyword like 'SONSUZUM').

   - Provide a "Kilitli Fotoğraf Galerisi" section. Each locked photo item features a lock icon, a text field to enter the secret code/datetime, and an "Aç" button.

   - When the user enters the correct code, that photo unlocks permanently and can be clicked.

3. Full-Screen Photo Modal (Lightbox):

   - Clicking an unlocked photo opens it in a full-screen view.

   - Include a prominent, accessible "X" close button in the top right corner.

   - Add a caption area under the image for custom romantic notes.

4. "Sana Özel Mektup" (Love Letter Section):

   - Provide a prominent letter section shaped like a romantic envelope.

   - The letter can either be unlocked automatically when all photo codes are revealed or opened with a main unlock button.

   - Design a beautifully styled modal or expanding card layout for reading the love letter text, with elegant typography and custom scrollbar design.

5. Digital Awards & Coupons:

   - A grid of unlockable digital coupons (e.g., "Sınırsız Sarılma Kuponu", "En Sevdiğin Filmi Seçme Hakkı", "Görüntülü Arama Ziyafeti").

   - Include a "Kullan" button on each card that marks it as redeemed with a cheerful confetti animation.

6. Localization & Design Guidelines:

   - UI language must be 100% natural Turkish.

   - Mobile-first, fully responsive design, with smooth page transitions and interactive micro-animations.

   - Use placeholder image URLs (Unsplash romantic themes) and sample Turkish love letter copy that can be easily replaced.
